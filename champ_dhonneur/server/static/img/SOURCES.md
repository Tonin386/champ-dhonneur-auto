# Provenance des images

Illustrations de *War Chest* (Trevor Benjamin & David Thompson, AEG), édition originale de
*Champ d'honneur*. Elles restent la propriété de leurs ayants droit : usage personnel uniquement,
à ne pas redistribuer.

| Fichiers | Source |
|---|---|
| `pieces/*.png` (unités, sceaux royaux, dos), `controle-*.png`, `sac.png`, `bois.png`, `lieu.svg`, `embleme.png`, `favicon.png` | https://warchestonline.com (réduites à 160 px pour les pièces) |
| `cartes/*.jpg` (cartes Unité, texte anglais), `regles/*` | https://www.yucata.de/en/Rules/WarChest |

Correspondance des pièces : A archer, B berserker, C cavalry, D ensign, E scout, F footman,
G royal guard, H light cavalry, K marshal, L lancer, M mercenary, N knight, P pikeman,
R warrior priest, S swordsman, X crossbowman. Blanc = loup (or), Noir = corbeau (argent).
